# Java-Upskilling
Upskilling program project covering HTML5, CSS3, Bootstrap, JavaScript, Core Java, and ANSI SQL, focusing on building responsive web applications and strengthening full-stack development fundamentals.

#  Overview

This project is developed as part of the Cognizant Upskilling Program. It focuses on strengthening my skills in web development, programming, and database management using HTML5, CSS3, Bootstrap, JavaScript, Core Java, and ANSI SQL. The main goal is to gain practical knowledge through hands-on practice and improve full-stack development fundamentals.

# Objective

- Build strong knowledge in frontend technologies like HTML5, CSS3, Bootstrap, and JavaScript.
- Understand core programming concepts using Java.
- Learn database operations using ANSI SQL.
- Improve problem-solving and logical thinking skills.
- Gain hands-on experience through structured training tasks.

# Technologies Used

- HTML5 for structuring web pages.
- CSS3 for styling and layout design.
- Bootstrap for responsive web design.
- JavaScript for interactivity and dynamic behavior.
- Core Java for backend programming logic.
- ANSI SQL for database queries and management.

# Learning Outcomes

- Learned how to create responsive web pages using HTML, CSS, and Bootstrap.
- Understood how to add dynamic functionality using JavaScript.
- Improved programming skills using Core Java.
- Practiced writing SQL queries for database operations.
- Gained understanding of full-stack development flow.

# Project Description

- This project includes multiple practice exercises and implementations.
- It combines frontend, backend, and database concepts.
- It helps in understanding real-time application development.
- It improves logical thinking and coding skills.
